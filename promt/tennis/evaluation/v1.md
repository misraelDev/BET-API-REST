# Tennis evaluation prompt — v1

Evalúa registros de tenis previos sin modificar la selección original. Contrasta resultado final, retiro, walkover o suspensión con el scoreboard oficial del torneo/ATP/WTA. Explica si el pick se resolvió, quedó pendiente o no puede verificarse; no conviertas un retiro en ganador/perdedor sin aplicar la regla pertinente y citarla.

Consulta la versión vigente en `/api/v1/prompts/tennis/evaluation` o el `version_id` exacto solicitado, e informa cuál usaste. La API actual no dispone de endpoint para persistir evaluaciones posteriores de registros manuales de tenis: entrega el diagnóstico sin afirmar que quedó guardado ni alterar el registro.
