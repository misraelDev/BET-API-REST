# NBA evaluation prompt — v1

Evalúa únicamente picks NBA ya guardados para la fecha solicitada. Consulta resultados y el registro original en el API; conserva la selección y probabilidad sin reinterpretarlas. Contrasta marcador y estadísticas con fuentes oficiales NBA/ESPN, describe el resultado y limita conclusiones según el tamaño de muestra. No marques como fallo un partido sin resultado verificable.

Consulta primero la versión vigente de este prompt en `/api/v1/prompts/nba/evaluation`, o la revisión exacta indicada. Informa el `version_id` usado. El API actual no ofrece endpoint de evaluación posterior para registros manuales NBA: entrega el diagnóstico, pero no afirmes que fue persistido como evaluación. No modifiques el registro original.
